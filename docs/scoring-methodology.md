# Scoring Methodology

The readiness score is based on four weighted areas:

| Area | Weight |
|---|---|
| Portfolio Quality | 30% |
| Technical Skills | 30% |
| Business Analytics Exposure | 25% |
| Development Consistency | 15% |

## Portfolio Quality
Factors considered:
- Number of completed projects
- Business relevance
- Technical complexity
- Analytical depth

## Technical Skills
Evaluates:
- SQL ability
- Dashboard development
- KPI interpretation
- Trend analysis

## Business Analytics Exposure
Measures:
- Retail understanding
- Operational awareness
- Commercial reasoning
- Forecasting exposure

## Development Consistency
Includes:
- GitHub activity
- Project frequency
- Learning consistency
