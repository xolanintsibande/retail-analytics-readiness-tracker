# Retail Analytics Hiring Readiness Tracker

AWS PartyRock application that evaluates readiness for Junior Data Analyst and Retail Analytics roles in Gauteng.

Built as part of the AWS AI & ML Scholars Program with Accenture and Udacity.

---

## Project Overview

This project was created to solve a common problem faced by aspiring data analysts:

You complete courses.
You build projects.
You learn SQL and Power BI.

But you still don't know whether you're genuinely ready to apply for analyst roles.

This application benchmarks portfolio strength, technical skills, and business analytics exposure against common requirements found across Junior Data Analyst and Retail Analytics job postings in Gauteng.

## Business Problem

Many aspiring analysts focus heavily on:
- Certificates
- Tool familiarity
- Course completion

But hiring managers care about whether candidates can solve business problems using data.

In retail analytics, this includes:
- Understanding customer behavior
- Explaining inventory trends
- Analyzing product returns
- Connecting analytics to revenue and operations

This project focuses on measuring readiness for those types of analytical challenges.

## Methodology

The scoring framework was designed using recurring patterns observed across Junior Data Analyst and Retail Analytics job postings in Gauteng.

Focus areas include:
- SQL proficiency
- Dashboard and reporting ability
- Analytical project experience
- Commercial understanding
- Consistency of technical practice

This project is intended as a learning and benchmarking tool rather than a formal hiring assessment.
